Model data was extracted from the supplied AC20-FZK-Haus IFC4 STEP content. 7 IfcSpace entities and 2 IfcBuildingStorey entities were parsed, with storey links derived from IfcRelAggregates. The extraction script uses a limited STEP entity parser for these specific records, not a full IFC library. Data are static JSON built from the actual file. Maintenance data in the HTML remain simulated. Upload index.html and ifc-data.json to the GitHub repository root. The IFC file itself does not need to be uploaded for site operation.
